# Сайт Авиаполис-Тура

Статичный сайт: HTML, CSS, JS. Сборка не нужна, открывается любым браузером или веб-сервером.

- `index.html` — главная
- `tri-stihii-urala.html` — маршрут «Три стихии Урала»
- `assets/css`, `assets/js` — стили и скрипты страниц
- `assets/img` — фото (WebP), логотипы (PNG)
- `assets/fonts` — Ordinar и Aviapolis (WOFF2)

Посмотреть локально: `python -m http.server 8000` в этой папке, затем http://localhost:8000

Перед запуском заменить заглушки: телефон, почта, ссылка на Telegram, отправка формы заявки.
